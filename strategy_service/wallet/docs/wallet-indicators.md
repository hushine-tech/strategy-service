# Wallet 指标公式与演算表格

> 对应代码(Phase C2b 前):`wallet/future.py` — `Position` / `FutureWallet`。
> Phase C2b 清理后,同一组公式由 `strategy_service/wallet/binance.py` 的
> `BinancePosition` / `BinanceFuturesBook` 实现;`wallet/future.py` 已删除。
> 本文档里出现的 `Position` / `FutureWallet` 名称保留为历史术语,分别对应
> 当前的 `BinancePosition` / `BinanceFuturesBook`。公式本身未变,仅代码
> 归属的文件与类名不同。

---

## 1. 通用参数

| 符号 | 含义 |
|------|------|
| `qty` | 持仓数量（≥0） |
| `dir` | 方向：+1 LONG / -1 SHORT / 0 无持仓 |
| `entry` | 平均入场价 `avg_entry_price` |
| `mark` | 标记价格 `mark_price` |
| `lev` | 杠杆倍数 `leverage` |
| `fr` | 手续费率 `fee_rate` |
| `IB` | `initial_balance`（逐仓：Position 级；全仓：FutureWallet 级） |
| `dep` | `deposit_sum` |
| `wd` | `withdrawal_sum` |
| `rpnl_gross` | `realized_pnl_gross_sum`（已实现毛利累计） |
| `close_fee` | `close_fee_sum`（平仓手续费累计） |
| `open_fee` | `open_fee_sum`（开仓手续费累计） |

## 2. Position 级指标

### 2.1 任何模式均可调用

| # | 指标 | 公式 |
|---|------|------|
| P1 | `get_unrealized_pnl()` | `qty × dir × (mark − entry)` |
| P2 | `get_realized_pnl()` | `rpnl_gross − close_fee` |
| P3 | `get_IM()` | `qty × entry / lev` |
| P4 | `get_margin_required()` | `qty × mark / lev` |
| P5 | `notional_at_mark()` | `qty × mark` |
| P6 | `get_maintenance_margin()` | `notional × mmr − cum`，其中 `(mmr, cum) = lookup_mmr_tier(notional)` |

### 2.2 仅逐仓可调用（全仓抛 RuntimeError）

| # | 指标 | 公式 |
|---|------|------|
| P7 | `_get_WB_raw()` | `IB + realized_pnl + dep − wd − IM − open_fee` |
| P8 | `get_wallet_balance()` | 同 P7 |
| P9 | `get_available_balance()` | `WB_raw + UPNL + IM − margin_required` |
| P10 | `get_position_equity()` | `IM + WB_raw + UPNL` |
| P11 | `get_liquidation_price()` LONG | `entry × (1 − 1/lev) / (1 − mmr)` |
| P12 | `get_liquidation_price()` SHORT | `entry × (1 + 1/lev) / (1 + mmr)` |

> P11/P12 的 `mmr` 取 `lookup_mmr_tier(qty × entry)` 的第一个返回值。

## 3. FutureWallet 级指标

| # | 指标 | 逐仓 | 全仓 |
|---|------|------|------|
| F1 | `get_unrealized_pnl()` | `Σ pos.UPNL` | 同左 |
| F2 | `get_wallet_balance()` | `Σ pos.get_wallet_balance()` | `IB_fw + Σ RPNL + dep_fw − wd_fw − Σ IM − Σ open_fee` |
| F3 | `get_available_balance()` | `Σ pos.AB` | `WB + Σ UPNL + Σ IM − Σ MR` |
| F4 | `get_total_position_equity()` | `Σ pos.Equity` | `WB + Σ UPNL + Σ IM` |
| F5 | `get_liquidation_price(sym)` 逐仓 | 委托 `pos.get_liquidation_price()` | — |
| F6 | `get_liquidation_price(sym)` 全仓 LONG | — | `(entry×qty − WB − UPNL_others − cum + MM_others) / (qty × (1 − mmr))` |
| F7 | `get_liquidation_price(sym)` 全仓 SHORT | — | `(entry×qty + WB + UPNL_others + cum − MM_others) / (qty × (1 + mmr))` |

---

## 4. open_position 三路径（one_way 模式）

| 路径 | 条件 | 效果 |
|------|------|------|
| flat→new | `qty == 0` | `qty = fill_qty; dir = direction; entry = fill_price; open_fee += fill_qty × fill_price × fr` |
| same dir→accumulate | `direction == current_dir` | `entry = (old_entry × old_qty + fill_price × fill_qty) / new_qty; qty += fill_qty; open_fee += …` |
| opposite→reduce/reverse | `direction != current_dir` | `close_qty = min(qty, fill_qty); gross = close_qty × dir × (fill_price − entry); close_fee += close_qty × fill_price × fr; qty -= close_qty;` 若 remaining > 0 反转 |

## 5. close_position（hedge 模式）

| 效果 |
|------|
| `gross = close_qty × dir × (close_price − entry); close_fee += close_qty × close_price × fr; qty -= close_qty` |

| notional 区间 | mmr | cum |
|---------------|-----|-----|
| ≤ 50,000 | 0.004 | 0 |
| ≤ 250,000 | 0.005 | 50 |
| ≤ 1,000,000 | 0.01 | 1,050 |
| ≤ 5,000,000 | 0.025 | 8,550 |
| > 5,000,000 | 0.05 | 18,550 |
